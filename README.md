              While Loop, For Loop and Functions

Introduction

This assignment is based on Python loops, control statements, and functions. I practiced using while loops, for loops, and functions by writing three simple Python programs.
The main purpose of this assignment is to understand how loops work, how to control loop execution, and how to create and call functions in Python.

1. Number Guessing Game – While Loop

To create a simple number guessing game using a while loop and control statements.
•	The program generates a random number between 1 and 10 using the random module.
•	The user needs to guess the correct number and gets a maximum of 3 valid attempts.
•	The program displays "Too high" or "Too low" for incorrect guesses.
•	Out-of-range guesses are rejected without using an attempt.
•	A correct guess displays a congratulations message and ends the loop.
•	If all attempts are used, the program displays "Better luck next time!"
•	Concepts Used: while, if, elif, else, break, continue, random.randint(), input().

2. Multiplication Table Generator – For Loop

To generate a multiplication table using a for loop and the range function.
•	The program asks the user to enter a number.
•	A for loop multiplies the entered number by each number from 1 to 10.
•	The range (1, 11) function generates numbers from 1 to 10.
•	The multiplication results are displayed line by line.
•	If the user enters 5, the program displays the multiplication table of 5 from 1 to 10
•	Concepts Used: for, range(), input(), int(), print().

3. BMI Calculator – Function

To calculate Body Mass Index (BMI) using a Python function.
•	A function named calculate BMI() is created.
•	The program asks the user to enter weight in kilograms and height in meters.
•	The function calculates BMI using the formula below.
•	The return statement returns the calculated BMI value.
•	The result is displayed with two decimal places.
•	BMI = Weight (kg) / Height (m)²
•	Concepts Used: def, function parameters, return, float(), function calling.
